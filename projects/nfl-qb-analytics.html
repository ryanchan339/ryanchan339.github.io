Overview

Built a React application for comparing quarterbacks, ranking players, and querying more than 20 statistics.

Architecture

A Flask and SQLAlchemy API serves data from normalized MySQL tables and ranking procedures. The Google Cloud SQL Connector connects the backend to its hosted database.

My contributions

  • Schema. Designed normalized MySQL tables for 20+ quarterback statistics.
  • Queries. Developed 7+ MySQL stored procedures for quarterback rankings, reducing backend query complexity.
  • API. Built a Flask and SQLAlchemy backend exposing 19 REST routes for analytics, authentication, and custom queries.
  • Cloud. Connected the backend to Google Cloud SQL through the Google Cloud SQL Connector.

Engineering focus

Translating player comparisons into SQL queries and exposing the results through a REST API.
