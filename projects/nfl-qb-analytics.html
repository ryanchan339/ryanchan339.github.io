Turn football statistics into a queryable application

I built a full-stack application for comparing NFL quarterbacks across more than 20 statistics. The project connects a normalized relational data model with database-driven rankings, custom statistical queries, and a React interface.

A relational core with an API boundary

I designed the MySQL schema to organize quarterback statistics and implemented stored procedures for ranking queries. A Flask and SQLAlchemy backend exposes the data through REST endpoints, connecting to Google Cloud SQL with the Google Cloud SQL Connector.

My contributions

  • Database design. Designed and implemented a normalized MySQL schema supporting more than 20 quarterback statistics.
  • Database-side queries. Developed more than seven stored procedures for quarterback rankings, reducing the amount of query logic handled by the backend.
  • API implementation. Built 19 REST routes for database-driven analytics, authentication, and custom statistical queries.
  • Cloud integration. Connected Flask and SQLAlchemy to the hosted MySQL database through the Google Cloud SQL Connector.

What the project demonstrates

This project brought together schema design, SQL, API development, and cloud connectivity in one application. The central engineering task was translating comparison and ranking questions into database queries, then exposing useful results to the frontend through a defined service layer.
