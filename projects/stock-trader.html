Stock Trader

A stock-ranking research pipeline with feature engineering, model evaluation, portfolio constraints, and a dashboard that makes every stage inspectable.

RoleIndependent project
Project periodApril–May 2026
Built withPython · Pandas · NumPy · scikit-learn · Alpaca API

The problem

Make the entire research loop visible

A stock prediction alone does not explain how a portfolio is built or whether a model adds useful information. This project connects data collection, ranking, allocation, and evaluation so the whole decision process can be inspected.

The approach

From prices to a constrained portfolio

The pipeline analyzes 50+ US large-cap equities using 20+ technical features. I engineered 15+ momentum, volatility, RSI, and cross-sectional ranking indicators to train a gradient-boosted model. Its ranking is blended with momentum before the top five stocks become portfolio targets.

01LearnBuild features and train on historical observations.
02AllocateRank candidates and apply exposure limits.
03AuditGenerate an order plan and record the outcome.

Engineering

Automation with a reviewable boundary

Automated portfolio generation and Alpaca paper-trading workflows rebalance the top-five allocations every five trading days. Individual holdings are capped at 15% and total exposure at 75%. A scheduled workflow refreshes data, trains the model, and generates a dry-run order plan; the dashboard reads saved report files.

Evaluation

Compare the model with simple alternatives

The reported 2024–2026 historical backtest returned 73.0%, compared with 55.5% for SPY over the same period. The gradient-boosted model achieved 51.1% ROC AUC across five walk-forward validation folds. The backtest measures simulated portfolio performance; walk-forward validation separately evaluates the model on held-out periods.
