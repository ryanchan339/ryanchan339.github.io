01Semantic video search

Video Search

A local video library you can search in natural language. Visual and spoken matches lead straight to the relevant timestamp.

RoleIndependent project
Project periodApril–July 2026
Built withPython · JavaScript · SigLIP

The problem

Searching inside a video

A video library is easy to collect and difficult to revisit. A filename cannot tell you where a particular scene appears, and a transcript misses moments that are only visible on screen. I wanted a search tool that could handle both.

The approach

Two ways to find the same moment

The visual pipeline samples frames and represents them with SigLIP embeddings. A separate pipeline transcribes speech with Whisper and embeds the text. A query searches both indexes, combines their standardized scores, and removes nearby duplicate hits.

01IndexSample frames and transcribe the audio.
02RankCompare the query with visual and text embeddings.
03SeekReturn matching moments with playable timestamps.

Engineering

Precision, speed, and a useful interface

Scene-based sampling avoids spending equal effort on every second of a video. The interface supports background indexing, library-wide or per-video search, and a ranking control that shifts emphasis between spoken and visual matches. Cosine similarity keeps the index simple at this scale.

Evaluation

A deliberate speed–quality tradeoff

The larger SigLIP configuration is the precision default; the smaller configuration makes indexing much faster. The project benchmark measured about 2.3 frames per second for so400m and 42 for base-224 on Apple Silicon. These are hardware-specific measurements, rather than a universal speed claim.
