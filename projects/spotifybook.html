03API integration · Web app

The SpotifyBook

A Flask application for exploring top tracks and artists, switching listening periods, and creating a playlist from a personal selection.

RoleIndependent project
Project periodJune–July 2025
Built withPython · Flask · Spotify API

The problem

Give listening history a simple interface

Spotify’s personal music data becomes more useful when you can move between time ranges and browse it directly. I built a small web application that connects those views with playlist creation.

The approach

An API-backed personal music view

Spotify OAuth connects an authorized session to personal listening data. Flask serves the pages and API routes, while JavaScript updates the track and artist lists when the selected time range changes.

01ConnectAuthorize a Spotify session.
02ExploreBrowse tracks and artists across listening periods.
03CollectCreate a playlist from the selected tracks.

Engineering

Keep updates focused

The track list refreshes through an API request instead of reloading the entire page. Navigation separates tracks and artists, and the backend handles playlist creation. A public search view provides another way to explore music without accessing personal listening history.

Demo notes

An illustrative listening session

The preview uses the repository’s track and artist templates with a curated selection of real songs and album artwork. The sample order illustrates time-range updates and does not represent anyone’s listening history. Artist icons use representative album covers. The hosted application’s personal-data features require Spotify access to be configured for the user.
