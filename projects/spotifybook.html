The SpotifyBook

Make personal music data easier to explore

Spotify’s listening data becomes more useful when you can move between time ranges and browse it directly. I built a web application that connects top-track and top-artist views with playlist creation.

An API-backed listening view

Spotify OAuth connects an authorized session to personal listening data. Flask serves the pages and API routes, while JavaScript updates the track and artist lists when the selected time range changes.

Keep updates focused

  • Update only the changing content. The track list refreshes through an API request instead of reloading the entire page.
  • Separate browsing from actions. Navigation separates tracks and artists, while the backend handles playlist creation from selected tracks.
  • Offer public exploration. A public search view provides another way to discover music without accessing personal listening history.

Preview and access notes

The walkthrough uses the repository’s track and artist templates with a curated selection of real songs and album artwork. Sample ordering illustrates time-range updates and does not represent anyone’s listening history. Artist icons use representative album covers.

The hosted application’s personal-data features require Spotify access to be configured for the user.
