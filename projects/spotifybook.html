The SpotifyBook

Explore top tracks and artists, switch listening periods, and create playlists through a Spotify-connected web application.

PythonFlaskJavaScriptSpotify API
View source ↗All projects ↗

Overview

Built a web application for browsing top tracks and artists across time ranges and creating playlists from selected tracks.

Authentication and data

Spotify OAuth authorizes access to listening data. Flask serves pages and API routes; JavaScript updates track and artist lists when the time range changes.

Features

  • Partial updates. Refresh track lists through API requests without reloading the page.
  • Playlists. Browse tracks and artists separately; create playlists from selected tracks.
  • Public search. Find music without accessing personal listening history.

Demo notes

The walkthrough uses the app’s templates with curated songs and artwork. The ordering is illustrative, not anyone’s listening history. Artist icons use representative album covers.

Personal-data features require Spotify access to be configured for the user.
